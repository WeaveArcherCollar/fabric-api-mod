# Fabric API — Core Mod Library

[![Download Latest](https://img.shields.io/github/v/release/WeaveArcherCollar/fabric-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/WeaveArcherCollar/fabric-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

The essential hooks and interoperability layer for Fabric mods, required by virtually every Fabric mod.

![Fabric API — Core Mod Library Preview](https://cdn.modrinth.com/data/P7dR8mSH/icon.png)

## Features

- Core event hooks for blocks, entities, and world generation
- Networking layer for client-server mod communication
- Resource loading and data pack integration APIs
- Registry sync for mod-added content across network
- Required dependency for 95% of all Fabric mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
